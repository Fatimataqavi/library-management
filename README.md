# Library Management System

A simple Library Management System built with Python, focusing on Object-Oriented Programming (OOP) concepts.

This project was developed as a learning exercise to practice classes, objects, object relationships, and data validation in Python.

## Features

- Add books to the library.
- Register new library members.
- Prevent duplicate books based on ISBN.
- Prevent duplicate members based on member ID.
- Search for books by title.
- Borrow books with a maximum limit of 3 books per member.
- Return borrowed books.
- Display library books and members.
- Generate a library report.
- Validate library data and detect data integrity issues.
